# DevOps Platform Project

## Overview

This repository contains a production-style end-to-end DevOps project built from scratch.

The goal of this project is to demonstrate modern DevOps practices using Docker, Kubernetes, GitHub Actions, GitOps, Infrastructure as Code, monitoring, and logging.

The project is being developed step-by-step with a focus on understanding every component rather than simply assembling tools.

## Planned Technologies

- Ubuntu 24.04 LTS
- Git
- GitHub
- Docker
- Kubernetes (Kind)
- Helm
- GitHub Actions
- Argo CD
- Terraform
- Prometheus
- Grafana
- Loki
- Fluent Bit
